# T-01 dependabot-review.yml に patch/minor かつ safe の時だけ auto-merge を有効化するジョブを追加する

## 目的
Dependabot の PR で、更新種別が patch または minor かつ AI の判定が safe の時だけ、AI とは別の権限を持つジョブが `gh pr merge --auto --squash` で auto-merge を有効化するようにする。

## 入力
- `vault/designs/D-20261013-dependabot-ai-merge.md`（「決定事項」表とフェーズ2 節。読むだけで変更しない）
- `.github/workflows/dependabot-review.yml`（フェーズ1 の実装。ジョブ `review`、ステップ id `metadata`・`claude`・`decide`・`label`）
- `.github/workflows/ci.yml`（必須チェックのジョブ名の参照用。変更しない）

## 成果物
- `.github/workflows/dependabot-review.yml`（1ファイル）

## 受け入れ基準
- YAML として読め、最上位の `permissions` が `{}`、起動契機が `pull_request` だけ、ジョブが `review` と `automerge` の2つ、`automerge` が `needs: review`、`automerge` の permissions がちょうど `contents: write`・`pull-requests: write`、`review` の permissions がちょうど `contents: read`・`pull-requests: write`・`issues: write` である（`python3 -c "import yaml,sys; d=yaml.safe_load(open(sys.argv[1])); j=d['jobs']; print(d['permissions']=={} and list(d[True])==['pull_request'] and set(j)=={'review','automerge'} and j['automerge']['needs'] in ('review',['review']) and j['automerge']['permissions']=={'contents':'write','pull-requests':'write'} and j['review']['permissions']=={'contents':'read','pull-requests':'write','issues':'write'})" .github/workflows/dependabot-review.yml` の出力が `True`）
- `automerge` ジョブの `if` を評価すると、PR の作成者が `dependabot[bot]`・更新種別が `version-update:semver-patch` か `version-update:semver-minor`・判定が `safe` の3条件をすべて満たす組み合わせの時だけ真になり（major・判定が空・作成者が別の時は偽）、`review` ジョブの `if` は `github.event.pull_request.user.login == 'dependabot[bot]'` のままである（`python3 -c "import yaml,sys,itertools; j=yaml.safe_load(open(sys.argv[1]))['jobs']; e=j['automerge']['if'].replace(chr(38)*2,' and ').replace(chr(124)*2,' or ').replace('github.event.pull_request.user.login','L').replace('needs.review.outputs.update-type','U').replace('needs.review.outputs.verdict','V'); P='version-update:semver-'; c=itertools.product(['dependabot[bot]','someone'],[P+'patch',P+'minor',P+'major',''],['safe','needs-human','']); print(j['review']['if'].replace(' ','')==chr(39).join(['github.event.pull_request.user.login==','dependabot[bot]','']) and all(eval(e,{'__builtins__':{}},{'L':l,'U':u,'V':v})==(l=='dependabot[bot]' and u in (P+'patch',P+'minor') and v=='safe') for l,u,v in c))" .github/workflows/dependabot-review.yml` の出力が `True`）
- `decide` ステップの `run` を判定の組み合わせごとに実行すると、`label` は従来どおり（safe かつ major 以外の時だけ `ai-review:safe`）で、`verdict` は AI の判定が `safe` の時だけ `safe`、それ以外（`needs-human`・空）は `needs-human` になる（`python3 -c "import yaml,sys; r=[x for x in yaml.safe_load(open(sys.argv[1]))['jobs']['review']['steps'] if x.get('id')=='decide'][0]['run']; P='version-update:semver-'; [print('export VERDICT='+v+' UPDATE_TYPE='+P+u+' GITHUB_OUTPUT=/dev/stdout', r, sep=chr(10)) for v,u in [('safe','patch'),('safe','minor'),('safe','major'),('needs-human','patch'),('','minor')]]" .github/workflows/dependabot-review.yml | bash` の出力が順に `label=ai-review:safe`・`verdict=safe`・`label=ai-review:safe`・`verdict=safe`・`label=ai-review:needs-human`・`verdict=safe`・`label=ai-review:needs-human`・`verdict=needs-human`・`label=ai-review:needs-human`・`verdict=needs-human` の10行）
- auto-merge の有効化は `automerge` ジョブの中の1つのステップだけが `gh pr merge` を `--auto` と `--squash` 付きで実行し、`automerge` ジョブに `uses:` のステップが無く、`review` ジョブ（AI の `claude_args` を含む）に `gh pr merge` の文字列が無い（`python3 -c "import yaml,sys; j=yaml.safe_load(open(sys.argv[1]))['jobs']; m='gh pr '+'merge'; s=j.get('automerge',{}).get('steps',[]); r=[x.get('run','') for x in s]; print(len([x for x in r if m in x])==1 and any(m in x and '--auto' in x and '--squash' in x for x in r) and all('uses' not in x for x in s) and m not in str(j['review']))" .github/workflows/dependabot-review.yml` の出力が `True`）
- `pull_request_target` と API キーを使わず、認証が OAuth トークンのままである（`grep -c -e pull_request_target -e anthropic_api_key -e ANTHROPIC_API_KEY .github/workflows/dependabot-review.yml` の出力が `0`、かつ `grep -c 'claude_code_oauth_token: ....secrets.CLAUDE_CODE_OAUTH_TOKEN' .github/workflows/dependabot-review.yml` の出力が `1`）
- 「このワークフローはマージしない」というフェーズ1 の記述が残っていない（`grep -c -e 'マージはしない' -e 'マージを行わない' .github/workflows/dependabot-review.yml` の出力が `0`）
- 計画ブランチとの分岐点からの差分に `.github/workflows/dependabot-review.yml` が含まれ、`.github/workflows/ci.yml` が含まれない（creator の worktree の中で `git diff --merge-base work/p-20261020-dependabot-automerge --name-only`）

## 決定済み
- ジョブ構成：既存の `review` ジョブ（`contents: read`・`pull-requests: write`・`issues: write`）は permissions・`if`・ステップ（`metadata`・`claude`・`decide`・`label`）を残す。新しいジョブ `automerge` を `review` の後ろに足す。ジョブ id は `automerge` とする
- `review` ジョブに `outputs:` を足し、`update-type: ${{ steps.metadata.outputs.update-type }}` と `verdict: ${{ steps.decide.outputs.verdict }}` の2つを出す。出力名はこの2つにする（`automerge` の `if` と T-02 の docs がこの名前を使う）
- `decide` ステップは既存の `label` の決め方を変えず、`verdict` を追加で出す。`verdict` は環境変数 `VERDICT`（AI の structured output）が `safe` の時だけ `safe`、それ以外（`needs-human`・空・取得失敗）は `needs-human` にする。`$GITHUB_OUTPUT` へは `label=...` の行を先に、`verdict=...` の行を後に書き、標準出力には何も出さない（受け入れ基準3の確認コマンドが `GITHUB_OUTPUT=/dev/stdout` で出力順を見るため）
- `automerge` ジョブ：`needs: review`、`runs-on: ubuntu-latest`、`timeout-minutes: 5`、permissions はちょうど `contents: write` と `pull-requests: write`。チェックアウトと claude-code-action は使わない（`uses:` のステップを置かない）。ステップは1つで、`env` に `GH_TOKEN: ${{ github.token }}`・`GH_REPO: ${{ github.repository }}`・`PR_NUMBER: ${{ github.event.pull_request.number }}` を渡し、`run: gh pr merge "$PR_NUMBER" --auto --squash` を実行する。`continue-on-error` は付けない（リポジトリで auto-merge が許可されていない時などの失敗を見えるようにする）
- `automerge` の `if` は `${{ }}` で囲まず、次の式をそのまま書く：`github.event.pull_request.user.login == 'dependabot[bot]' && (needs.review.outputs.update-type == 'version-update:semver-patch' || needs.review.outputs.update-type == 'version-update:semver-minor') && needs.review.outputs.verdict == 'safe'`。式に使う参照はこの3つ（`github.event.pull_request.user.login`・`needs.review.outputs.update-type`・`needs.review.outputs.verdict`）と `==`・`&&`・`||`・括弧・単一引用符の文字列だけにし、`always()` などの関数や `semver-major` は書かない（受け入れ基準2の確認コマンドがこの形を Python の式に置き換えて評価する）。状態関数を書かないので、`review` ジョブが失敗した時は `automerge` は動かない（それでよい）
- auto-merge は有効化するだけで、ワークフローは CI の完了を待たない。必須チェックが通った時点で GitHub がマージする
- AI（`claude` ステップ）の `claude_args` の `--allowedTools` は変えない（`gh pr merge` を許可しない）
- 認証は `claude_code_oauth_token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}` のまま変えない。`anthropic_api_key`・`ANTHROPIC_API_KEY` は書かない。`pull_request_target` は使わない
- フェーズ1 の「マージしない」の記述を書き換える。1行目のコメントは `# Dependabot の PR を AI で影響確認して判定ラベルとコメントを付け、patch・minor かつ AI の判定が safe の時だけ auto-merge を有効化する` にする。`label` ステップのコメント本文の `echo "このワークフローはマージを行わない。"` は `echo "Dependabot の patch・minor の更新で AI の判定が safe の時だけ auto-merge を有効化する。必須チェックが通った時点で GitHub がマージする。"` に置き換える
- `.github/workflows/ci.yml` と他のワークフローは変更しない。ブランチ保護・auto-merge の許可・シークレットはワークフローや API から設定しない（人がリポジトリ設定で行う。T-02 で docs に書く）
- actionlint は環境に無いので使わない。YAML の構文は受け入れ基準1の `yaml.safe_load` で確かめる（PyYAML は `on:` を真偽値の `True` のキーとして読むので、確認コマンドは `d[True]` を見る）
- 実際の Dependabot PR での動作確認は求めない（main へのマージ後でないと起動しないため）
